# Tantalar — Requirements Traceability

Maps every PRD story (1–32) to exactly one owning phase, named components, acceptance tests, and documentation. Phase docs live in [phases/](phases/). "Owner phase" is the phase that may not exit without the story demonstrably working.

## Scope defect flag (resolved by TAN-047)

Earlier revisions listed four items under "In Scope (v1)" whose own wording contradicted v1 scope. TAN-047 moved them to "Out of Scope (v1)" in PRD.md with one consistent statement each: disc image playback, polished hardware-acceleration tuning UI, multi-server federation/sync, and the Overseerr-style request portal. The settled all-in-one boundary is now explicit in the PRD: embedded download engines are core; external daemons are optional integration plugins only.

## Cross-cutting requirements

- Event-log coverage for every new operation: standing rule in every phase doc.
- Dual-engine migration greenness: gate on every phase exit (ADR-009).
- GPL-free core artifacts + license report: ADR-016, enforced in CI from Phase 1.
- Fresh reviewer acceptance at each phase exit: ADR-017.
- MCP surfaces: one owner phase per surface, per [ADR-0018](adrs/0018-mcp-server-plugin.md) and the [MCP contract](mcp-server.md). Phase 2 owns the server shell and generic surface; domain phases own only tools/resources for capabilities that already exist in that phase. No privileged bypass: public contract access only. Reads on by default; mutations off by default, opt-in plus scoped; V1-forbidden tool classes never ship at any phase. Immutable audit event for every MCP call.
