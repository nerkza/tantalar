## Getting help

- Bug reports and feature requests: GitHub Issues.
- Security issues: [SECURITY.md](../SECURITY.md), never a public issue.
- Questions about contributing: [CONTRIBUTING.md](../CONTRIBUTING.md).

v1 is a self-hosted media server. Community support is best-effort; there is
no paid support channel for v1.

## What to include in a bug report

- Tantalar version (image tag or commit).
- Database engine: SQLite or PostgreSQL.
- Docker command or compose file used.
- Relevant server logs, with credentials, API keys, and tunnel secrets
  removed.
