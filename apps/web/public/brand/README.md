# Tantalar application artwork

These exports come from the approved Modular A acid-lime kit (7 September 2026).
The editable masters remain in the local, Git-excluded `docs/brand-local/acid-lime/` directory.

- `logo-dark.svg`: `logos/tantalar-horizontal-dark.svg`.
- `logo-light.svg`: `logos/tantalar-horizontal-light.svg`.
- `favicon.svg` and `favicon-32.png`: the matching 32-pixel icon exports.
- `apple-touch-icon.png`: the 180-pixel icon export.

Keep the supplied square corners, proportions, clear space, and complete outlined wordmark.
The application logos omit the outlined initial T: the lime symbol supplies that letter.
The remaining “antalar” outlines move left by 110 units; the canvas width is 890 units.
`BrandLogo` selects the logo through the application's Mantine colour scheme.
The interface palette and typography remain controlled by the existing theme system.
